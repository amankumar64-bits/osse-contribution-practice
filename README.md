
# SAP WILP Open Source Software Engineering Lab

## Lab 2: Git and GitHub Contribution Workflow

### Objective
Learn how contributors collaborate on an open-source project using Git and GitHub.

### Activities
1. Explore the repository.
2. Fork the repository.
3. Clone the fork to a local machine.
4. Configure Git remotes.
5. Create a feature branch.
6. Make and commit a change.
7. Push the branch to GitHub.
8. Create a Pull Request.
9. Review the contribution.

### Contribution Task
Add your name and a short learning goal to the `CONTRIBUTORS.md` file.

### Important
This is a practice repository created for learning Git and GitHub workflows.
